# 🛡️ Log-Based Intrusion Detection System (IDS)

A lightweight Intrusion Detection System that analyzes log files and detects:

- Brute-force attacks  
- Port scanning attempts  
- Unauthorized sudo (admin) access  

## 📌 Features
- Uses regex-based pattern detection
- Reads system/auth logs
- Saves alerts into a JSON file
- Very simple, fast, and beginner-friendly
